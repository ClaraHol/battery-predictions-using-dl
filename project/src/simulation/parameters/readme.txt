The pouch cells uses propriotary data about there design which is not aviable to us. This means we cannot simulate using the true features when generating data for the SBI. We instead use the results of 2 other papers to estimate the true value of the missing parameters. The first Chen et al. (2020) https://iopscience.iop.org/article/10.1149/1945-7111/ab9050 describes the features of batteries with the same chemstries. We then apply to results of https://iopscience.iop.org/article/10.1149/1945-7111/ac4e11 to upscale the total cross sectional area to match the charge capacity.
